# TeleVip 3.6.17 phone display coverage

Date: 2026-10-31 (Asia/Taipei).
Version: `3.6.17-telegram-13.1.1-api102`, versionCode 359, package `org.televip`.
Target: connected Google Play Telegram 13.1.1 (72371), Android 16, LSPosed API 102.

## Report and cause

With Hide Phone enabled, the Profile tab still showed the account phone, and Settings > Account > Tap to change phone number showed it in the `Keep <phone>` label. Both were reproduced on the phone. The Account list itself was already masked.

The old formatter mask only entered scopes around settings row construction and `ProfileActivity.updateProfileData`. Profile phone rows are formatted later by the list adapter's row binder, after that scope has ended. The number-change introduction builds a separate view and was never covered.

## Fix

- Enter the same display-only mask while binding profile rows. Resolve the adapter from the profile's field types, typed constructor and phone-formatter calls; obtain the account from its exact, validated owning-profile field.
- Enter the mask while building the change-number introduction, identified by its `PhoneNumberKeepButton` label and typed view-builder signature. R8's merged helper class is resolved by fingerprint, not a hardcoded obfuscated name.
- Preserve existing formatter matching: only a number equal to the owning account's phone is replaced by dots, only within the UI scope. Account objects, persistence and phone-change actions are not rewritten. Thread-local/nested cleanup remains unchanged.
- Refresh fingerprint cache version to 22. The compatibility gate requires the two new UI methods and correct profile-owner field, checks their formatter calls, and rejects deliberately broken mappings.
