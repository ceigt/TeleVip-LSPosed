## Imported fixes

- TeleVIP `a1081a3818927ba6ed59b744a439315a017d1bc0`: Local Premium previously forced `UserConfig.isPremium()` during download startup. Preserve the original answer within the typed start method, so Telegram chooses its connection policy for the actual account. Nested calls and exceptional completion restore the thread scope. If the scope hook is unavailable, Local Premium does not spoof the answer; hook installation remains incomplete and retryable.
- Gate the speed boost on the server-backed `currentUser.premium` field of the download operation's `currentAccount`. This deliberately differs from upstream's selected-account lookup, which can refer to another account during a background download. The host still sets its normal parameters for ordinary accounts. Existing switches and their stored values are retained. No throughput improvement has been measured on Play in this update.
- TeleVIP `1dcc7e6`: select the populated legacy profile status overlay or primary status line used in Telegram 13.1. Guard short view arrays and prevent appending the same complete ID twice. Rendering and clipping still require a device check.
- Fingerprint cache version 19 adds the typed download start and the account field passed to `getInstance`. Existing privacy request policy, callbacks, stored history and media lifecycles are unchanged.
