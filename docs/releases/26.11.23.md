## Independently implemented features

The behavior review uses MaiHoku commit 9b68c55a9cc1b67f6c5b549d80d9f179e9a44532. See THIRD_PARTY_NOTICES.txt for provenance and source licensing.

All six new switches default off. Existing settings are retained.

- Mutual contact markers in the native contacts list.
- Profile ID and photo DC, with the current connection DC as a self-account fallback, and a long-press copy menu.
- Normal/source-free forwarding choice before native send, remembered separately per account.
- Optional Google translation through Telegram's native translation requests, with bounded background work, per-account source capture, cancellation and response limits.
- User-configured API ID/hash, applied to native network initialization and SMS authentication requests after restarting.
- Optional SMS login profile, including Firebase/Passkey changes and the official invoice choice scoped to the SMS fee page.

Translation sends the requested text to Google only when its switch is enabled. Translation strips source formatting entities because their offsets do not describe the translated text. DC denotes the cached profile photo's server, with the documented self fallback.
