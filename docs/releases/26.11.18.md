# TeleVip 26.11.18 verification

## Download tuning

TGSpeed+ 4.2.0 prompted this review of connection rotation. TeleVip uses Telegram's own connection selection on compatible Play builds. A regular-account operation of at least 32 MiB with the active native 2 MiB budget can rotate through four slots. The rotation uses Telegram's chunk sizes, request caps and native budget. The original send path records the chosen slot for cancellation and retry. The hook leaves explicit retry slots, Stories, forced-small-chunk fallback and the existing real-Premium settings to their original paths. See [third-party notices](../../THIRD_PARTY_NOTICES.txt).
