## Verification tooling improvement

Privacy protocol checks now inspect actual request decoder calls, rather than just checking that the send dispatcher can be hooked. Eleven known read/typing/online/story request decoders must match the module's Bool, affectedMessages or Vector completion. Four response constructors, eight field types and ordinary/timestamp delegate interfaces are checked. Four negative controls remove the Bool response, replace the story Vector, remove the offline field and replace the timestamp interface; each must fail.

This supplements the existing media/ad/phone/settings shape checks and the conservative source inventory. It does not prove full control flow, server-side receipt visibility or end-to-end media behavior.
